# V3 — parked for now

## The conversational AI coach

`coach.tsx` is the complete chat screen (already working, as code), taken out of the navigation
while the infrastructure it needs is set up.

To bring it back:
1. Move this file to `app/(tabs)/coach.tsx`.
2. Add the `<Tabs.Screen name="coach" .../>` entry back to `app/(tabs)/_layout.tsx` (the git
   history has the exact block).
3. Remove `"future-v3"` from the `exclude` array in `tsconfig.json`.
4. Follow the “conversational AI coach” section of the main README to deploy the server function
   (an Anthropic account plus `supabase functions deploy coach`).

The rest of the infrastructure (`src/lib/coach.ts`, `supabase/functions/coach/`, the
`coach_messages` table) is already in place and needs nothing done to it.

## The AI fitness coach (programmes generated by Claude, plus chat)

`fitnessAi.ts` and `fitness-chat.tsx` call the `fitness-coach` Edge Function, which has Claude
design the programme, the meals and the shopping list. They are parked because the free rule-based
generator ([src/features/fitness/planGenerator.ts](../src/features/fitness/planGenerator.ts)) does
the job at no cost, instantly, and without any health data leaving the user's own rows.

To bring it back:
1. Move `fitnessAi.ts` to `src/lib/fitnessAi.ts` and `fitness-chat.tsx` to `app/fitness/chat.tsx`.
2. Point the generation in [src/lib/fitness.ts](../src/lib/fitness.ts) at the AI client rather than
   at `generateFitnessPlan`.
3. Remove `"future-v3"` from the `exclude` array in `tsconfig.json`.
4. Deploy the function: `npx supabase functions deploy fitness-coach`, with `ANTHROPIC_API_KEY`
   set as a secret.

Note on language: these screens were written in French and were translated with the rest of the app
in 1.2, so bringing them back does not reintroduce French into an English build.
